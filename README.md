# Монополия · Москва

Приватная браузерная настольная игра для 2–6 друзей. Московское поле с авторскими местами, шесть фишек, анимации броска и движения, общий игровой сервер, обмены с комментариями и личные чаты. Проект работает без Discord и без регистрации. В голосовом канале можно общаться параллельно.

## Запуск на этом компьютере

Нужен Node.js 22.18+ или более новая поддерживаемая версия.

```sh
cd monopoly
npm ci --cache ./work/npm-cache
npm run dev
```

Открыть http://localhost:3000. Создать комнату и поделиться ссылкой. «Сначала попробовать с ботами» запускает партию с тремя ботами.

На macOS можно дважды нажать `Запустить Квартал.command`: скрипт соберёт игру, запустит сервер и откроет браузер. Окно терминала нужно оставить открытым на время игры. Если macOS предлагает выбрать приложение, откройте файл через Terminal.

Для собранной версии:

```sh
npm run build
npm start
```

Порт можно задать через `PORT`, папку сохранений — через `DATA_DIR`.

## Как подключить друзей

- На одном компьютере — открыть разные браузерные профили. Один профиль хранит один текущий вход в `localStorage`; две вкладки этого профиля обычно откроют одного игрока.
- В одной Wi-Fi-сети — друзья открывают `http://<локальный IP компьютера>:3000` и вводят код комнаты. Компьютер с сервером должен работать, а сетевой доступ к порту 3000 должен быть разрешён.
- Из интернета — нужен постоянно работающий Node.js-хостинг или VPS. Веб-сервер должен поддерживать WebSocket на `/ws`, HTTPS и постоянный диск для `DATA_DIR`. Локальная ссылка `localhost` с другого компьютера не откроется. Публикация в интернет пока не выполнена.

Можно развернуть через приложенный Dockerfile:

```sh
docker build -t kvartal .
docker run --name kvartal -p 3000:3000 -v kvartal-data:/app/data kvartal
```

Docker-конфигурация подготовлена, но в текущей среде не проверялась.

## Что реализовано

- Приватные комнаты по шестизначному коду; лобби, выбор фишки, готовность, добавление/удаление ботов.
- 40 клеток: 22 участка, 4 станции метро, 2 коммунальные службы, налоги, карты, тюрьма, парковка, старт.
- Покупки, пошаговые аукционы, аренда, полные цветные районы, равномерное строительство домов и отелей.
- Залоги и выкуп, продажа зданий, погашение долга, банкротство, победитель и итоговый капитал.
- Обмены участками и деньгами: предложение, личный комментарий, принятие, отклонение, отзыв. Подтверждение привязано к конкретному предложению: старой кнопкой нельзя принять новые условия.
- Личные чаты между людьми в одной комнате. История, сообщения к обменам и непрочитанные сохраняются. Сервер отправляет переписку только её двум участникам. Это обычное серверное хранение, без сквозного шифрования.
- Боты для самостоятельной игры; автоматические решения по таймеру; режим без таймера; короткие партии по числу кругов.
- Атомарные JSON-снимки на диске, восстановление после перезапуска, автоматическое переподключение браузера.
- Поворот и масштабирование поля, вид сверху, список всех клеток, управление собственностью, звуки и реакции.
- Компоновка для узких экранов и резервная карта при недоступном WebGL.

Вход в партию хранится в браузере. Не очищайте данные сайта, если хотите вернуться под тем же игроком. После выхода из активной партии кнопка возврата доступна в той же вкладке. В начавшуюся партию новые игроки не добавляются.

## Правила этой версии

Это самостоятельная игра о торговле недвижимостью с собственными названиями и оформлением. Начальный баланс — 1 500 ₽, проход старта — 200 ₽. Полный цветной район удваивает базовую аренду пустого участка. До 4 домов, затем отель; строительство и продажа равномерные. В банке 32 дома и 12 отелей. Последнее здание при нескольких претендентах продаётся на аукционе с выбором участка. При нехватке четырёх домов для размена отеля доступна продажа всей застройки группы. Свободная парковка не выдаёт налоговый банк.

Залог приносит 50% цены участка, выкуп стоит 55%. На заложенном участке аренды нет. Перед обменом нужно продать здания группы. Заложенная собственность передаётся: получатель платит 10% суммы залога или сразу выкупает залог за 110% его суммы. Такое же решение требуется при наследовании имущества банкрота. Имущество банкрота перед банком выставляется на последовательные аукционы. Карты выхода можно обменивать; они сохраняют принадлежность своей колоде и возвращаются после использования. Строительство, продажа и залог доступны вне своего хода. Здания при банкротстве продаются за половину цены в пользу кредитора. Выход из тюрьмы: дубль, карта или 50 ₽; на третьем неудачном броске сбор обязателен.

В короткой партии капитал считается как наличные + полная цена незаложенных участков + половина цены заложенных + половина цены построек. При равенстве капиталов побеждает более ранний игрок в порядке входа. Круги считаются по исходному числу игроков, включая выбывших.

## Где менять оформление

Оформление отделено от правил:

- `client/appearance.js` — яркость, освещение, свечение окон, исходная камера.
- `client/scene.js` — геометрия города, модели фишек, анимации и кубики.
- `client/style.css` — цвета интерфейса, типографика и расположение панелей.
- `client/main.js` — интерфейс комнат, предложений, чатов и хода.
- `shared/board.mjs` — названия клеток, группы, цены и аренда.
- `server/game.mjs` — правила, деньги, действия и боты.
- `server/index.mjs` — комнаты, входы, WebSocket, сохранения и приватная доставка сообщений.

Полная московская раскладка: `outputs/Карта-Москвы.md`. Новое поле запускается в новой комнате: прежние сохранения остаются на диске, но не смешиваются с новой группировкой.

Московские миниатюры находятся в `client/landmarks.js`. При застройке растёт миниатюра участка, точки показывают уровень. В восточной группе четыре района: для строительства нужно собрать все четыре.

Ранние концепты находятся в `design/`. Вариант `kvartal-night-concept-v2.png` учитывает пожелание приглушить свет в центре. Это художественный ориентир, а не обещание точного совпадения процедурной 3D-сцены с изображением.

## Проверка

```sh
npm test
npm run build
```

Тесты проверяют правила, 30 полных партий ботов, приватность переписки с тремя подключениями, обмен, защиту от старого подтверждения и восстановление после перезапуска. В браузере вручную проверены вход двух игроков, готовность, запуск, личное сообщение, предложение и принятие сделки.

## Границы текущей версии

Приложение рассчитано на небольшой частный сервер и один процесс Node.js. Все комнаты сохраняются одним JSON-файлом. Нет аккаунтов, межкомнатной переписки, зрительского режима и интеграции Discord Activities. Хостинг и постоянный HTTPS-адрес не настроены. Боты используют простую стратегию. Полная живая партия с вашей компанией и проверка на реальных телефонах ещё нужны.

Визуальная часть — работающая стилизованная 3D-версия с процедурными моделями; дальнейшая художественная полировка может выполняться независимо от правил.
